# 🍽️ Cucina Mia — Pianificatore Pasti

App web gratuita per pianificare i pasti settimanali e generare automaticamente la lista della spesa.

## ✨ Funzionalità

- **📅 Pianificatore settimanale** — Aggiungi colazione, pranzo e cena per ogni giorno
- **🛒 Lista della spesa automatica** — Generata dagli ingredienti dei pasti inseriti, raggruppata per categoria
- **📖 Libreria ricette** — Salva le tue ricette preferite e usale rapidamente nel pianificatore
- **✅ Spunta gli articoli** — Barra gli ingredienti già acquistati
- **🖨️ Stampa / Copia** — Esporta la lista della spesa
- **💾 Dati salvati localmente** — Tutto nel browser, nessun account richiesto

## 🚀 Come usare

### Online (GitHub Pages)
1. Fai il fork di questo repository
2. Vai su **Settings → Pages**
3. Imposta la source su `main` branch, cartella `/ (root)`
4. L'app sarà disponibile su `https://tuousername.github.io/cucina-mia`

### In locale
Basta aprire `index.html` nel browser — nessuna installazione necessaria!

## 📱 Come funziona

1. **Pianificatore** → Clicca `+ aggiungi` su un giorno/pasto → inserisci piatto e ingredienti
2. **Lista Spesa** → Viene generata automaticamente dalla settimana corrente
3. **Ricette** → Salva ricette con ingredienti, riusale velocemente nel pianificatore

## 💻 Tecnologie

- HTML/CSS/JS puri — zero dipendenze, zero server
- `localStorage` per il salvataggio dei dati nel browser
- Funziona su desktop e mobile
